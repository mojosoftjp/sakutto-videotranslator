更新履歴

さくっと動画翻訳のバージョンごとの変更内容です。最新版は Microsoft Store 版・ダウンロード版とも同じ内容です。

v1.2.0

2026年10月5日
  • AI翻訳のモデルを最新世代に更新しました（Gemini 3.8 Flash / GPT-6.1 / Claude Sonnet 5.5・Opus 5.5 など）。古いモデルを設定していた場合は、推奨モデルに自動で切り替わります
  • APIキーを Windows の暗号化機能で保護して保存するようにしました（以前のバージョンで保存したキーも自動で暗号化されます）
  • 選んだAIモデルが、次に起動したときに初期設定へ戻ってしまう問題を修正しました
  • AIが一部の行の翻訳を返さなかった場合は、その行だけを原文のまま残し、件数を表示するようにしました（字幕の行がずれる問題も修正しました）
  • Claude の一部モデル（Sonnet 5 / Opus 5）で翻訳に失敗することがある問題を修正しました
  • 確認モードで開く「字幕の確認・編集」画面が白い画面のまま表示されない問題を修正しました
  • AIの選択肢を「ローカルLLM（LM Studio・Ollama など）」と分かりやすい名前にし、ローカルLLMにはクラウド用のAPIキーを送信しないようにしました

v1.1.2

2026年8月31日
  • AI翻訳のモデルを最新世代に更新しました（Gemini 3.7 Flash / GPT-5.6 / Claude Sonnet 5・Opus 5 など）
  • 最新のOpenAIモデルで翻訳に失敗する問題を修正しました
  • 一部の環境でモデル読み込み中に強制終了する問題への対策を追加しました（GPUで問題が起きた場合は自動的にCPUモードに切り替わります。設定から手動で切り替えることもできます）
  • モデル読み込み完了時に、使用中のランタイム（GPU / CPU）を表示するようにしました

v1.1.1

2026年5月30日
  • アプリ内にヘルプボタンを追加し、使い方ガイドをすぐ開けるようにしました

v1.1.0

2026年5月29日
  • WMV形式で出力した動画が正しく再生されない問題を修正しました
  • 処理中にエラーが起きた際、内容が分かるように表示を改善しました

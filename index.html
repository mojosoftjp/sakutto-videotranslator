動画の多言語対応に必要な機能を

文字起こしから吹き替えまで、このアプリひとつで完結します。

📝 文字起こし

高精度な文字起こし

OpenAI Whisper をお使いのPC上で実行。音声をクラウドに送らずに字幕の元データを作成します。

  • small / medium / large-v3-turbo / large-v3 から選択
  • SRT / VTT 字幕ファイルの書き出し
🌐 AI翻訳

AIで自然に翻訳

Gemini・OpenAI・Claude などのAIサービス、またはローカルLLM（LM Studio・Ollama など）で翻訳できます。

  • 翻訳先は 7 言語から選択
  • 焼き付け前に字幕を確認・編集
🎬 字幕焼き付け

字幕を動画に焼き込み

文字の大きさ・色（白／黄）・表示位置（上／中央／下）を選んで、字幕を動画に直接焼き込みます。

  • 文字の大きさ・色・位置を選べる
  • 複数の動画をバッチ処理
🎙️ AI吹き替え

7言語のAI吹き替え

翻訳した内容を音声化し、吹き替え動画を生成。元音声とのミックス／置き換えを選べます。

  • 日本語・英語・中国語・韓国語・仏・独・西
  • 男声・女声を選択

データの流れ

どの処理が PC の中で終わり、どの処理でインターネットに送るかをまとめました。

💻

PC の中で終わる処理

  • 動画からの音声の取り出し
  • 文字起こし（OpenAI Whisper）
  • 字幕ファイルの作成・字幕の焼き付け・動画の書き出し
  • ローカル LLM（LM Studio・Ollama など）での翻訳（お使いの環境で動きます）
🌐

インターネットに送る処理

  • クラウドの AI で翻訳するとき: 字幕の文章だけを、選んだ AI サービス（Google Gemini・OpenAI・Anthropic Claude）に送ります。音声や動画は送りません
  • 吹き替えのとき: 読み上げる字幕の文章（AI 翻訳を使うときは翻訳後の文章）を、Microsoft のオンライン音声合成（Edge TTS）に送ります
  • 最初に文字起こしのモデルをダウンロードするとき（Hugging Face から）

開発元（Mojosoft）に動画・音声・文章が送られることはありません。アカウント登録も、利用状況の収集もありません。詳しくは プライバシーポリシー をご覧ください。

よくある質問（FAQ）

できないことも含めて、お答えします。

Q. YouTube の動画を URL から翻訳できますか？

いいえ。URL は入力できません。お手元の動画・音声ファイル（ご自身で作った動画や、利用を許可された動画）を読み込んで使います。YouTube で見るだけなら、YouTube の自動翻訳字幕もお試しください。

Q. インターネットにつながっていなくても使えますか？

文字起こしは、最初に文字起こしのモデルをダウンロードしたあとは、オフラインで使えます。翻訳は、ローカル LLM（LM Studio・Ollama など）を使えばお使いの環境の中で行えます。クラウドの AI での翻訳と、吹き替え（Microsoft のオンライン音声合成）には、インターネット接続が必要です。

Q. 月額料金はかかりますか？

かかりません。アプリは ¥2,950 の買い切りです。クラウドの AI（Gemini・OpenAI・Claude）で翻訳する場合のみ、その AI サービスの利用料が、お客様の API キーを通じて各社から請求されることがあります。

Q. API キーは必要ですか？

文字起こしと、ローカル LLM での翻訳には不要です。Gemini・OpenAI・Claude で翻訳する場合は、そのサービスの API キーが必要です。吹き替えの音声合成そのものに API キーは要りませんが、ほかの言語に吹き替えるには AI 翻訳を使います。

Q. 翻訳前と翻訳後の 2 言語を並べた字幕は作れますか？

いいえ。出力される字幕は 1 つの言語です（AI 翻訳を使うと翻訳後の言語、使わないと話している言語）。

Q. 翻訳結果を直してから字幕にできますか？

はい。「確認モード」をオンにすると、焼き付けの前に字幕の文章を確認・修正できます。確認モードが開くのは、リストに入れたファイルが 1 本だけのときです（2 本以上をまとめて処理するときは開きません）。直せるのは文章だけで、字幕の表示タイミングは変更できません。

Q. 長い動画も処理できますか？

Microsoft Store 版と、購入後のダウンロード版には、動画の長さの制限はありません。ダウンロード版の無料試用は、1 本 5 分までです。処理にかかる時間は、動画の長さと PC の性能によって変わります。

Q. Mac で使えますか？

いいえ。Windows（64 ビット）専用です。

そのほかの質問は 使い方ガイド をご覧ください。

v1.2.0

2026年10月5日

  • AI翻訳のモデルを最新世代に更新しました（Gemini 3.8 Flash / GPT-6.1 / Claude Sonnet 5.5・Opus 5.5 など）。古いモデルを設定していた場合は、推奨モデルに自動で切り替わります

  • 選んだAIモデルが、次に起動したときに初期設定へ戻ってしまう問題を修正しました
  • AIが一部の行の翻訳を返さなかった場合は、その行だけを原文のまま残し、件数を表示するようにしました（字幕の行がずれる問題も修正しました）
  • Claude の一部モデル（Sonnet 5 / Opus 5）で翻訳に失敗することがある問題を修正しました
  • 確認モードで開く「字幕の確認・編集」画面が白い画面のまま表示されない問題を修正しました
  • AIの選択肢を「ローカルLLM（LM Studio・Ollama など）」と分かりやすい名前にし、ローカルLLMにはクラウド用のAPIキーを送信しないようにしました

Changelog

What changed in each version of Snap Video Translator. The Store and download editions share the same latest build.

v1.2.0

October 5, 2026
  • Updated the AI translation models to the latest generation (Gemini 3.8 Flash, GPT-6.1, Claude Sonnet 5.5 / Opus 5.5, and more). If an older model was selected, the app switches to the recommended one automatically
  • Your API key is now stored encrypted with Windows data protection (keys saved by earlier versions are encrypted automatically)
  • Fixed the selected AI model resetting to the default on the next launch
  • If the AI returns no translation for some lines, only those lines keep the original text and the app shows how many (subtitles no longer shift out of place)
  • Fixed translation failures with some Claude models (Sonnet 5 / Opus 5)
  • Fixed the blank subtitle review/edit window in Review mode
  • Renamed the AI option to "Local LLM (LM Studio, Ollama, etc.)" and stopped sending your cloud API key to a local LLM

v1.1.2

August 31, 2026
  • Updated the AI translation models to the latest generation (Gemini 3.7 Flash, GPT-5.6, Claude Sonnet 5 / Opus 5, and more)
  • Fixed translation failures with the latest OpenAI models
  • Added protection against crashes while loading the speech model on some systems (it falls back to CPU mode automatically; you can also switch manually in settings)
  • The model status now shows which runtime is in use (GPU / CPU)

v1.1.1

May 30, 2026
  • Added an in-app Help button that opens the user guide right away

v1.1.0

May 29, 2026
  • Fixed video output not playing correctly in WMV format
  • Improved the error messages shown when processing fails
